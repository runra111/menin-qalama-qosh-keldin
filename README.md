# Менің қалама қош келдің

Презентация на казахском языке (СӨЖ, ЖҚТ A1). Начинается как экскурсия по Алматы от здания ҚБТУ, а потом улетает в космос: Сатурн, Нептун и чёрная дыра.

**Открыть:** index.html в Chrome или Edge, или по ссылке GitHub Pages этого репозитория.

## Управление

| Клавиша | Действие |
| --- | --- |
| → / пробел / клик | дальше |
| ← | назад |
| N | текст речи на экране |
| M | звук вкл/выкл |
| F | полный экран |

Звук включается после первого нажатия клавиши. После слайда «Рақмет» есть пасхалка: нажми → ещё раз.

## Что внутри

- `index.html` — готовая презентация одним файлом, работает без интернета
- `Сценарий.md` — текст речи на казахском с переводом
- `build/` — исходники: сцены на three.js, шейдеры (планеты, линзирование чёрной дыры), процедурный звук на Web Audio
- `assets/` — текстуры, геометрия планет, звёздное облако, модели персонажей

## Сборка

```bash
cd build
npm install
node build.mjs
```

Скрипт собирает всё в один HTML-файл `../Презентация.html`.
