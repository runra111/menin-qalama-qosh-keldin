# Менің қалама қош келдің

Презентация на казахском языке (СӨЖ, ЖҚТ A1). Начинается как экскурсия по Алматы от здания ҚБТУ, а потом улетает в космос: Сатурн, Нептун и чёрная дыра.

**Открыть:** по ссылке GitHub Pages этого репозитория, в Chrome или Edge.

## Управление

| Клавиша | Действие |
| --- | --- |
| → / пробел / клик | дальше |
| ← | назад |
| N | текст речи на экране |
| M | звук и музыка вкл/выкл |
| F | полный экран |

Звук и музыка включаются после первого нажатия клавиши. После слайда «Рақмет» есть пасхалка: нажми → ещё раз.

## Что внутри

- `index.html` — презентация (сцены на three.js, шейдеры планет и линзирования чёрной дыры, процедурные звуки)
- `music/` — музыка: Deftones (Сатурн), Soundgarden «Black Hole Sun» (Нептун и чёрная дыра), песня для пасхалки. Страница подгружает их рядом с собой
- `Сценарий.md` — текст речи на казахском с переводом
- `build/` — исходники
- `assets/` — текстуры, геометрия планет, звёздное облако, модели персонажей, музыка

## Сборка

```bash
cd build
npm install
node build.mjs
```

Скрипт собирает `../github/index.html` (версия для этого сайта) и `../Презентация.html` (один файл со встроенной музыкой, открывается без интернета).
